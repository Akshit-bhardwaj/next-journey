Next.js Architecture Overview

This repository demonstrates the foundational architecture of Next.js, focusing on the App Router structure and core file responsibilities.

Key Concepts
page.js: Defines the UI for a route and serves as the primary entry point for rendering content.
layout.js: Provides a shared layout structure that wraps pages and enables consistent UI across the application.

Architecture Flow
```
---
|
layout.js
|
page.js

---
```

Objective

To understand and apply Next.js file-based routing and component hierarchy for building scalable applications.
